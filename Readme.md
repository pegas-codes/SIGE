# SIGE-UC — Prototype

Static frontend prototype for the "Salon International des Grandes Écoles et Universités du Cameroun" (SIGE-UC).

## What this is

A set of mobile-first HTML/CSS/JS prototype pages that demonstrate a student and exhibitor experience for a hybrid education fair. The project is intentionally static so you can preview and adapt the UI quickly.

## Quick start

Open any of these files in a modern browser (no build step required):

- [sige-uc-app.html](sige-uc-app.html)
- [src/pages/dashboard-expo.html](src/pages/dashboard-expo.html)
- [src/pages/student-profile.html](src/pages/student-profile.html)
- [src/pages/test.html](src/pages/test.html)

## Primary files

- `sige-uc-app.html` — main mobile dashboard prototype
- `src/React.js` — React-style component (ES module) mirroring the prototype flow
- `src/pages/` — additional standalone demo pages
- `assets/images/` — image assets used in the UI

## Notes

- Uses CDN assets: Font Awesome, Google Fonts, and Tailwind (in some pages).
- No `package.json` or build tooling included — this is a static prototype.
